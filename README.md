📘 Описание проекта

Это решение для хакатона Альфа-Банка (2025), где участникам требовалось разработать систему поиска релевантных фрагментов из веб-источников для ответов на вопросы пользователей.

Мы реализовали retrieval-based pipeline на основе модели e5-large, протестировали множество концепций (dense search, BM25, hybrid search, chunking, reranking), и нашли оптимальный подход, обеспечивший:

👉 Hit@5 = 23.54% (лучший результат нашей команды)

👉 91 место из 180 команд

Проект выполнялся командой из 4 человек, где моя роль включала:

- разработку и улучшение ML-пайплайна

- эксперименты с embedding-моделями

- гибридный поиск (BM25 + dense)

- создание финального submission

- координацию команды и помощь с репозиторием и окружением
